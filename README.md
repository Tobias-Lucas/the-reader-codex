# The Reader Codex

Gerenciador pessoal de leitura desenvolvido em Python com CustomTkinter.

Projeto criado com foco em:
- organização de livros, mangás e outras categorias;
- acompanhamento de progresso de leitura;
- histórico de avanços;
- arquitetura evolutiva e local-first;
- sincronização opcional com Google Sheets e Google Drive.
